Créer une activité

Chaque activité du site est un simple fichier texte placé dans le dossier _activites/ du dépôt GitHub. Dès qu'il est enregistré, GitHub fabrique la page de l'activité et ajoute sa tuile dans la page de sa discipline, sous la bonne rubrique. Aucun logiciel n'est nécessaire : tout se fait sur github.com.

En 4 étapes

  1. Ouvrez le modèle : Créer une activité sur GitHub ↗
    Le bouton ouvre l'éditeur de GitHub avec une fiche déjà préremplie (il faut être connecté au compte qui gère le dépôt).
  2. Nommez le fichier : remplacez nouvelle-activite.md par un nom court, en minuscules, sans accents ni espaces, par exemple danse-des-oiseaux.md. Ce nom devient l'adresse de la page.
  3. Remplissez la fiche : modifiez l'en-tête (entre les deux lignes ---) puis le texte des sections. Les lignes qui commencent par # dans l'en-tête sont des commentaires : vous pouvez les laisser ou les effacer.
  4. Enregistrez : cliquez sur Commit changes… puis à nouveau sur Commit changes. La page est en ligne une à deux minutes plus tard.

Modifier ou retirer une activité

Ouvrez le fichier dans le dossier _activites/ sur GitHub et cliquez sur le crayon pour le modifier, ou sur Delete file dans le menu … pour le retirer. Le site se met à jour automatiquement.

Le modèle complet

Pour travailler hors ligne, copiez ce modèle dans un nouveau fichier .md :

---
# ─── En-tête de la fiche (à remplir) ───────────────────────────────
titre: Titre de l'activité
sous_titre: Une phrase qui précise l'activité (facultatif)

# Discipline : musique-web, musique-tablette, danse, art-dramatique, arts-plastiques ou oiseau-de-feu
discipline: danse
# Rubrique : doit être identique à une rubrique de la page de la discipline
# (ex. danse : Langage de la danse, Technique du mouvement, Énergie)
categorie: Langage de la danse
# Position dans la rubrique (1 = en premier)
ordre: 10

auteurs: Prénom Nom, enseignante en danse
realisation: Réalisation en équipe
niveau: À partir du 2e cycle du primaire
duree: 1 à 2 périodes

# Image : téléverser d'abord l'image dans le dossier images/, puis indiquer son chemin
# image: /images/mon-image.jpg

# Lien vers la console Fonofone utilisée (facultatif)
# et son code QR (image carrée téléversée dans images/, facultatif)
# qr_code: /images/mon-code-qr.png
# console_nom: Fono-image
# console: https://fonofone.org/fonoweb-image/

gratuite: true
---
